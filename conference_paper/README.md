## Version 2: restructured after the "too generic" feedback

The first draft read like a thesis summary. Strong benchmark papers on this topic share a different structure:
- Wen et al., *Medical Image Analysis* 2020;
- Yagis et al., *Scientific Reports* 2021 (Springer Nature);
- Rumala, Springer LNCS / MICCAI workshop 2023.

They:
1. **Open with a hook figure that quantifies the problem.** This draft now has **Fig. 1, the leakage gap**: literature accuracies grouped by split level, with Yagis's same-data experiment and our results.
2. **Ask explicit research questions** and answer each with a matched experiment. RQ1 asks whether adding a ViT helps; RQ2 asks which component carries the signal (a branch ablation using Swin–ViT as the control); RQ3 asks whether the XAI maps are anatomically conclusive.
3. **Formalize the protocol** with notation for the subject-disjoint split and subject-level aggregation, so the "leakage-free" claim is checkable.
4. **Show the controlled design in one figure** (Fig. 2, TikZ vector): only the backbone changes.
5. **Report clinical metrics and uncertainty.** Balanced accuracy with 95% bootstrap CIs, sensitivity, specificity, fold-paired tests, and folds won.
6. **Organize results as numbered "Findings"** rather than "Results of model X".
7. **End with actionable recommendations** (a 6-item checklist) as a contribution of its own.
8. **Cite the newest related work:** the 2025 *Diagnostics* scoping review on leakage, the 2023 LNCS split study, and a concurrent 2026 subject-level 3D CNN preprint.

The new statistics are computed by `analysis/derived_stats.py` from numbers already in the thesis (fold-wise macro-F1 and pooled confusion matrices); it ran no new experiments. Figures 1 and 3 are generated by `analysis/make_figures.py` as vector PDFs, using a colour-blind-checked palette with marker shapes so they also read in grayscale print.

## Version 5: rewritten in the style of M3T (CVPR 2022)

The paper now follows the presentation conventions of Jang & Hwang, *M3T*, CVPR 2022. Only the style was adopted; no sentences were copied.

| M3T convention | Applied here |
|---|---|
| "Name: description" title | **HyBench3D**: A Leakage-free Benchmark of … |
| Abstract opens with "In this study, we propose …", then data numbers, then results, then "This study demonstrates …" | same flow |
| **Fig. 1 = overall framework**, top-right of page 1 beside the abstract | TikZ framework, blocks (a)–(e) |
| **Fig. 2 = NC vs AD brain** in the introduction | CN vs AD in axial/coronal/sagittal planes (subject IDs cropped out) |
| Intro order: CNN → transformer → hybrids → AD clinical motivation → "In this study, we propose …" | same order |
| Contributions as "First, … Second, … Third, …" paragraphs | four paragraphs |
| Methods: "consists of five main blocks: 1) … 2) …", one subsection per block | Preprocessing / Split / Feature extraction / Fusion & classification / Evaluation |
| Bold operators and explicit dimensions (e.g. a feature map in ℝ^{C×L×W×H}), numbered equations each followed by "where …" | **P**, **D**_cnn, **D**_vit, **z** ∈ ℝ^1408, losses, sampler, aggregation (8 equations) |
| Experiments: Dataset (with approval statement) → Implementation details (optimizer, betas, LR, batch, GPU) → Comparison → Ablation (w/o rows) → Visualization | same subsections |
| Results table with a **Params** column; ablation table with **"w/o …"** rows | Table I (Params + GFLOPs), Table III (w/o ViT branch, CNN → Swin) |
| Conclusion opens with "In this paper, we proposed …" | same |

**Kept from our own standards, which M3T lacks:** subject-level CIs, paired tests, majority and demographic baselines, and a short limitations paragraph. **Not copied:** M3T's grammar slips and its 4-decimal precision, because our fold means are only known to 3 decimals.

**Trimmed for 6 pages:** the "leakage gap" figure was removed (it remains in `figures/` and is regenerated by `analysis/make_figures.py`). Its message stays in the text with citations.
